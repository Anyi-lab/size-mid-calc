    计算规则

    设基本尺寸 D，上偏差 ES，下偏差 EI
    最大极限尺寸D + ES
    最小极限尺寸D + EI
    公差T = ES − EI
    中差（偏差中间值）(ES + EI) ÷ 2
    中间值D + (ES + EI) ÷ 2 = (最大 + 最小) ÷ 2
    算例：238.25 0.00 -0.51
    最大 = 238.25 + 0.00 = 238.250　最小 = 238.25 + (−0.51) = 237.740
    公差 = 0.00 − (−0.51) = 0.510　中差 = (0.00 + (−0.51)) ÷ 2 = −0.255
    中间值 = 238.25 + (−0.255) = 237.995

    校验规则（每项显示实际算式）

    ① 数值有效基本尺寸与上下偏差均可解析为数字
    ② 上偏差 ≥ 下偏差否则按大小自动重排并提示
    ③ 公差大于 0公差为 0 时提示（无加工余量）
    ④ 极限尺寸顺序最小 ≤ 中间值 ≤ 最大
    ⑤ 中间值 = (最大 + 最小) ÷ 2用极限尺寸反推中间值，与结果比对
    ⑥ 中间值 = 基本尺寸 + 中差用偏差路线独立复算一次
    ⑦ 独立整数复算把数值放大成整数（微米级）再算一遍，与小数运算逐位比对，排除浮点误差
    ⑧ 反算上下极限中间值 ± 公差÷2 应还原出最大 / 最小极限尺寸
    ⑨ 显示取整提示结果被舍入显示时给出原值提示
    精度选「自动」时：小数位按输入自动取；中差多一位时自动补一位（如 0.51 → 0.255）。
    批量模式每行单独校验，结果列显示 ✔ 通过 / ⚠ 提示 / ✖ 异常。
